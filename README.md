# NISEBURA（ニセブラ）

ふっとばして場外へ！ 最大4人で遊べる、ブラウザ向けのオリジナル2D対戦アクションゲームです。
スマートフォン（タッチ操作）とPC（キーボード・ゲームパッド）の両方で動きます。

- 攻撃を当てると相手の **ダメージ％** が増え、％が高いほど遠くへ吹っ飛ぶ
- ステージの外までふっとばせば **撃墜**。ストックが尽きたら負け
- 弱・強・スマッシュ（ため可）・空中攻撃・必殺技4種・つかみ投げ・ガード・回避・崖つかまり・受け身・ずらし
- CPU（Lv1〜9）、トレーニングモード（動かない相手）
- キャラクター・ステージ・効果音・BGMはすべてプログラムで生成したオリジナル（外部素材なし）

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド不要・依存ライブラリなし）。
スマホで遊ぶ場合は GitHub Pages などで公開したURLを開き、横向きにしてください。

ローカルサーバーで開く場合:

```sh
npx serve .
```

## ステージ

天空の闘技場（足場なし）／夕焼けガーデン（足場3つ）／ネオンシティ（動く足場）／灼熱の火山（上下する足場）

## 操作

### タッチ
画面左半分をドラッグで移動（はじくとダッシュ）。右側のボタンで 攻撃・スマッシュ・必殺・ジャンプ・ガード・つかみ。
ガード＋攻撃でもつかみ。

### キーボード
| | キーボード1 | キーボード2 |
|---|---|---|
| 移動 | W A S D（1人の時は矢印キーも可） | 矢印キー |
| 攻撃 | J（Z） | , / テンキー1 |
| 必殺 | K（X） | . / テンキー2 |
| ジャンプ | L / Space（C） | / / テンキー3 |
| ガード・回避 | I / 左Shift（V） | 右Shift / テンキー0 |
| スマッシュ | U（N）／方向と攻撃の同時押し | M / テンキー4 |
| つかみ | O（B） | ; / テンキー5 |
| ポーズ | Esc | |

### ゲームパッド
左スティック/十字キー: 移動、A: 攻撃、B: 必殺、X・Y: ジャンプ、LB・RB: つかみ、LT・RT: ガード、右スティック: スマッシュ、START: ポーズ

## 開発者向け

```
index.html          画面構成
css/style.css       メニューUIのスタイル
js/util.js          汎用関数
js/audio.js         WebAudioによる効果音・BGM合成
js/input.js         キーボード・ゲームパッド・タッチ入力
js/skeleton.js      IK骨格とポーズ補間
js/moves.js         技データの形式と共通技
js/characters.js    キャラクター定義（性能・必殺技・配色）
js/fighter.js       ファイターの状態遷移・物理・被弾処理
js/projectiles.js   飛び道具
js/effects.js       ヒットエフェクト等
js/render-fighter.js キャラクター描画
js/stages.js        ステージと背景
js/ai.js            CPU
js/battle.js        バトル進行・当たり判定・カメラ・HUD
js/ui.js            メニュー画面
js/main.js          起動とメインループ
tools/              テスト・検証用スクリプト
```

検証用スクリプト:

```sh
node tools/sim.js 60 7          # CPU同士を60試合走らせて勝率・撃墜％・自滅率を集計
node tools/controls-test.js     # 実ブラウザでキーボード操作から各アクションが出るか確認（要 playwright）
node tools/shots.js shots all   # 各画面のスクリーンショット（要 playwright）
node tools/shots.js shots closeup  # キャラの拡大図（全カラー・状態別）
node tools/shots.js shots faces    # 顔の表情一覧
```
